# DevBlog (Dev.to Clone)

A full-stack multi-user blogging platform inspired by Dev.to, built with Python and Django. Users can publish articles, organize posts with tags, leave comments, and manage content through a customized admin interface.

## Features

- **Article Management:** Create, read, and browse developer articles with automatic unique slug generation.
- **Tagging System:** Categorize posts using `ManyToMany` tag relationships for easy topic filtering.
- **Commenting System:** Interactive discussion section under each blog post.
- **Custom Admin Panel:** Tailored Django Admin interface for efficient management of posts, tags, and comments.
- **Responsive UI:** Clean, developer-friendly layout built with semantic HTML5 and custom CSS.

## Tech Stack

- **Backend:** Python, Django
- **Database:** SQLite3
- **Frontend:** HTML5, CSS3, Django Template Engine
- **Media & Image Handling:** Pillow
